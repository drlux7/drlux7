# 🧾 SmartBilling

A graduation-project style smart billing system built around a Raspberry Pi.

## Architecture

```text
[Smart Scale / Dummy Scale]
          ↓
   Raspberry Pi 3 B+
          ↓
 Edge Impulse / Python
          ↓
      Flask API
          ↓
       Web UI
          ↓
   Billing / QR Payment
```

## Highlights

- Raspberry Pi 3 B+
- Debian Linux
- Python / Flask
- Edge Impulse model inference
- Dummy Scale Mode for local development
- QR payment workflow
- Auto-refreshing interface
- Hardware + software integration

## Why it matters

This project demonstrates that I can work beyond a normal web stack and connect **hardware, AI, backend services, and user interfaces** into one system.
